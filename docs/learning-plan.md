# 学习计划

## 1. 我理解系统要解决什么问题

我认为这是一个“科研团队的记账本”。
团队有一笔总经费，就是要算好三笔钱：还能用的（可用）、正在申请还没批下来的（冻结）、已经花掉的（已使用）。不管怎么操作，这三笔钱加起来必须等于总经费，而且绝对不能出现负数。
流程大概就是：成员发起申请 -> 钱被冻结 -> 老师审批（批了继续冻着，拒了退回可用） -> 最后财务结算
